# 베이지 UI 별도 버전

기존 Re:Tone 서버에서 `/beige/` 경로로 열 수 있도록 만든 실험용 화면입니다. 기존 `/` 화면과 `public/`의 기존 파일 6개는 수정하지 않았습니다.

이 버전은 기존 `app.js`를 그대로 불러오므로 로그인, 친구, 채팅, 일정, AI 점검은 같은 API를 사용합니다. `beige.js`가 화면 구조를 바꾸고 `beige.css`가 베이지 스타일을 적용합니다.

서버와 데이터베이스가 없는 상태에서 `index.html` 파일만 열면 로그인 API를 사용할 수 없습니다. 화면 확인용 예시 데이터 캡처는 `design-preview/2026-11-11/beige-app-*.png`에 있습니다.
